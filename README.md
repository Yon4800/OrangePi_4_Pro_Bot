# OrangePi 4 Pro Bot

OrangePi 4 Pro（おぱじ・フォプロ）の Mastodon / Hollo 対応AIボットです。マウントを取ってくるので注意です。

## 主な機能
- **`+LLM`**: キャラクター会話（開発者判定・スレッド履歴・添付画像対応）
- **`+M`**: 回線速度（Download / Upload / Ping / ISP）と CPU/RAM 状態を測定して報告
- **`+TALK`**: 他SBCボットとのグループ会話リレー（2周・全8回）
- **定期投稿**: 毎日 12:00 / 15:00 / 22:00 / 02:00 に自動投稿
- **APIリトライ / フォールバック**: Gemini API の 503/429 エラー時に自動リトライおよび別モデルへのフォールバックを実行
